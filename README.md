# METROPOLIS — короткий эдит для YouTube Shorts

Готовый вертикальный эдит о фильме Фрица Ланга **«Метрополис» (1927)**.

- **Файл:** `output/metropolis_shorts.mp4`
- **Формат:** 1080 × 1920 (9:16), 30 fps, H.264 + AAC, 31,2 секунды
- **Монтаж:** 13 тактов при 100 BPM; титры и монтажные удары синхронизированы с авторским саундтреком
- **Текст:** русский, встроенные кинетические титры

## Концепция

Мини-трейлер начинается с вопроса о будущем, показывает контраст города наверху и машинного мира внизу, а затем приводит к главной гуманистической мысли фильма: между головой и руками должно быть сердце. Финальная карточка даёт название, режиссёра и год, не обрывая эмоциональную точку.

## Прозрачность по материалам

Это **оригинальный концепт-эдит по мотивам фильма**, а не нарезка исходного фильма: три иллюстрации созданы специально для проекта, музыка синтезирована с нуля. В ролике нет исходных кадров, оригинального саундтрека или голосовой дорожки фильма. Это позволяет использовать ролик как авторскую визуальную интерпретацию, не выдавая новую графику за архивный материал.

## Пересборка

Нужны Python 3.10+ и FFmpeg. Бинарный FFmpeg может поставляться через пакет `imageio-ffmpeg`.

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python render_short.py
```

По умолчанию ролик записывается в `output/metropolis_shorts.mp4`. Можно указать другой путь:

```bash
python render_short.py --output output/my_cut.mp4
```
